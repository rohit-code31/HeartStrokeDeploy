# HeartStrokeDeploy
Heart Disease Prediction System ❤️

This project is a Machine Learning-based Heart Disease Prediction System that uses the K-Nearest Neighbors (KNN) algorithm to predict the likelihood of heart disease based on patient medical data. The model is trained on heart health parameters and deployed through a user-friendly web application built with Python.

Features
Predicts risk of heart disease from patient health information
K-Nearest Neighbors (KNN) classification model
Data preprocessing and feature scaling
Interactive web interface for real-time predictions
Pre-trained model saved using Pickle
Easy deployment and usage
Tech Stack
Python
Scikit-learn
Pandas
NumPy
Streamlit/Flask (depending on your app.py implementation)
Pickle


Project Structure
├── HeartPrjt.ipynb      # Model training and analysis
├── app.py               # Web application
├── KNN_heart.pkl        # Trained KNN model
├── scaler.pkl           # Feature scaler
├── columns.pkl          # Feature column information
├── requirements.txt     # Dependencies



Objective

The goal of this project is to assist in the early detection of potential heart disease risks by leveraging machine learning techniques and providing quick predictions through an accessible web-based interface.
